# Consulta y herramientas — rol 3

**Integrante:** ______________________________

Aquí se implementarán el enrutador de intención, herramientas de búsqueda y extracción, comparación de versiones, generación de respuestas y lista de verificación, además de la vista para el analista.

**Entrada:** pregunta del usuario y contexto autenticado; evidencia entregada por recuperación.

**Salida:** respuesta estructurada con `answer`, `sources`, `abstained`, `tool_used` y `needs_human_review`, más checklist con citas.

Ver [responsabilidades e integración](../../../docs/roles/Asignacion_de_roles.md#rol-3--consulta-y-herramientas).
